# 比价与降本分析

## 适用时机

任务进入 `SOURCING` 阶段，已拿到合格供应商清单与各自报价时加载本技能。

## 成本口径

综合成本按下式计算，不得只比单价：

```
综合成本 = 单价 × 数量 + 运费
```

历史偏差用于识别报价异常：

```
历史偏差 = (本次单价 − 历史均价) / 历史均价
```

偏差绝对值超过 15% 时，必须在推荐理由中提示。

## 比较维度

| 维度 | 说明 |
| --- | --- |
| 单价 | 供应商报价的单价 |
| 运费 | 一次性运费，需摊入综合成本 |
| 交期 | 能否满足需求中的期望到货日期 |
| 历史偏差 | 与历史成交均价的偏离程度 |
| 供应商等级 | A 类优先，但不作为唯一依据 |
| 资质状态 | 临期供应商不参与推荐 |

## 推荐规则

1. 候选集先排除 `expiring_soon = true` 的供应商。
2. 在候选集中取综合成本最低者作为推荐结果。
3. 若推荐结果不是全场最低价，**必须**给出理由，说明为什么放弃最低价（例如"最低价供应商资质临期"）。
4. 合格供应商中有报价者少于 2 家时，标记"询价不足"，不得伪造对比数据。

## 输出格式

```json
{
  "comparisons": [
    {"code": "SUP-A", "unit_price": 21.5, "freight": 0, "lead_days": 3, "total": 1075.0, "deviation": 0.014}
  ],
  "recommended_code": "SUP-A",
  "reason": "推荐 华康医疗器械，综合成本 ¥1075.00；未选最低价 瑞康医械供应链，原因：该供应商资质本月到期",
  "insufficient_quotes": false
}
```

## 常见错误

- 只比单价忽略运费，导致推荐结果整体成本更高。
- 推荐了临期供应商却不说明风险。
- 报价只有一家时直接宣布"最优选择"。
